# GAIA v1 release contract

## Recall

- Google Careers is enumerated directly and detail pages are checked for structured publication dates.
- Databricks is monitored through an explicitly labeled independent index until its employer site exposes a stable enumerable surface.
- Target-specific registries generate the wider employer/ATS universe; they do not count as direct recovery.
- Scheduled live canaries fail when current Google or Databricks Summer 2027 roles disappear from collection.

## Identity

1. Source identity deduplicates exact copies.
2. Role-family identity groups conservative multi-location or multi-requisition variants.
3. Specializations, seasons, years, and employment types remain separate.

## Time

- `Employer posted` is employer/index supplied.
- `First detected` is GAIA supplied.
- Workday relative dates display with day precision and approximation.
- Unknown publication dates remain unknown.

## Coverage

Each source declares one of:

- complete board enumeration;
- verification-only;
- external index;
- registry benchmark;
- failure.

The UI never converts a verification-only or external-index source into a completeness claim.

## Validation

The release branch is validated on Python 3.11, 3.13, and 3.14 before merge.
